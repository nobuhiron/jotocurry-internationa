# 英訳スタイルガイド

対象: `src/data/translations.ts` の `en` テキスト全般。
目的: 海外フランチャイズ出店検討者への訴求において、誤読されず、ブランドの品位に合う英語を保つ。

## 1. 読者設定

- 読者は英語ネイティブではなく、**英語を国際共通語として読む事業者**（実績: タイ・韓国・モンゴル）。
- 「格好いいネイティブ英語」より「平易で誤読されない英語」を優先する。
- 短文（1文1メッセージ）。基本語彙。イディオム・句動詞の連鎖・言葉遊びは使わない。
  - NG例: `with the wind at your back`, `hit the ground running`

## 2. トーン: 静かな自信

- 事実と数字で語る落ち着いた文体。ブランドの「和・上質」に合わせる。
- 誇張形容詞（amazing / incredible）、煽り（Don't miss out! / Act now）は禁止。
- 読者への直接話法（we / you）で「一緒にやる」姿勢は明確に出す。
- 基準文: トップページ About の英文。

### 2b. 見出し・キャッチはキレを優先する

本文の「静かな自信」に対し、**見出し・ヒーロー・ボタンは短く・強く・リズムよく**。品位は保ちつつ、切れ味を意識する。

- 目安8語以内。関係詞節（who / that 〜）や of の連鎖が入ったら刈る。
- 弱い動詞・事務的な動詞を避ける: ~~View~~ → See / Read / Meet、~~We introduce〜~~ は使わない。
- 抽象語より数字・固有名詞で具体化する。
- 例: ~~Voices from Franchise Owners Who Decided to Open~~ → **Why Owners Chose Joto Curry**

## 3. 忠実度はセクション種別で変える

| セクション | 方針 |
|---|---|
| 見出し・キャッチ・ボタン | 意訳OK（効果の等価を優先） |
| 事業説明・サポート内容 | 意味は忠実、構文は英語流に再構成 |
| FAQ・数字・契約条件 | 忠実訳。事実の増減禁止 |
| 法務（privacy / cookie） | 直訳寄り、正確性第一 |
| 自動返信メール | 英文ビジネスメールの定型に置き換え |

## 5. 表記規則

- 見出し・ボタンは **Title Case**。完全文の見出しのみ Sentence case。
- 数字は算用数字＋千区切りカンマ（5,000 meals）。年号にはカンマを付けない（1983）。
- **Oxford comma** を使う（A, B, and C）。
- em dash は前後スペース付き（` — `）。
- 日本語固有名詞はマクロンなしローマ字（udon, katsu, Joto）。

## 6. 創業年の表記（日英共通）

- 年号で言える場所（ラベル・キャッチ・meta）: **「1983年創業」/ Proven Success Since 1983**
- 期間でしか言えない場所（本文中）: **「40年以上」/ more than 40 years**
- 「40年」単体（以上なし）は使わない（毎年陳腐化し、2026年時点で既に43年のため）。

## 7. 進め方

セクションごとに「対訳表で提案 → 合意 → 適用」。無断での書き換えはしない。
